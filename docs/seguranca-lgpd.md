# Segurança, privacidade e LGPD

## Privacidade e minimização
O formulário deve receber somente informações necessárias para a comunicação.

## LGPD
Em uso real, a organização precisaria definir finalidade, base legal, controles de acesso, retenção, descarte, responsabilidades e políticas de uso.

## Alucinações
- o Redator é instruído a não inventar fatos;
- o Revisor compara a saída com os dados originais;
- informações essenciais ausentes podem ser sinalizadas;
- cenários de maior risco passam por revisão humana.

## Vieses
A linguagem gerada pode refletir vieses do modelo ou do contexto. Revisão humana continua importante em situações de impacto relevante.

## Segurança das informações
Este repositório não inclui API Keys ou credenciais locais.

## Limite do protótipo
O CorpAI é um protótipo acadêmico e não implementa todos os controles de um ambiente corporativo de produção.
